# HIGHFLY GENESIS — Primera prueba móvil G1/G2

Proyecto **independiente**, no modifica UNIFIED/CLEAN/REBORN.

## Probar

Abrir `https://drakentzy07.github.io/HIGHFLY-GENESIS/` solo después del despliegue verde. En móvil, usar joystick a la izquierda y arrastrar a la derecha para cámara. ATK, salto, dash, skill y USAR. Editor permite añadir objetos y esculpir.

## Estado importante

Esta prueba tiene relieve aproximado y editor HIGHFLY reducido. NO es aún el motor de terreno original completo ni su editor nativo. Ver `docs/STATUS.md`.

## Código

`npm install && npm run build && npm test`.

## Activar Pages

Settings > Pages > Build and deployment > Source: GitHub Actions. El workflow `.github/workflows/pages.yml` despliega en cada push.
